# Historical Crawlora plugin scaffold

The maintained native plugin has moved to
[Crawlora-org/crawlora-openclaw-plugin](https://github.com/Crawlora-org/crawlora-openclaw-plugin).
Use that repository's installation guide, source, tests, and release process.
The source in this directory is retained for history and is not the current
published package.

The `crawlora-mcp` package catalog contains 4684 tools across 534 platform groups; the hosted endpoint is `https://mcp.crawlora.net/mcp`.
